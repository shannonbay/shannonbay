# Hi, I'm Shannon

Senior software engineer in Wellington, New Zealand. Fifteen years of integration and platform work: real-time telecoms at Metaswitch, emergency-call routing at Spark, and border systems at New Zealand Customs. These days I also build and ship apps with AI coding agents.

## Apps I've shipped

- **[Crate](https://shannonbay.github.io/crate/)**: a music player for Windows built around albums and artists. Bulk tag editing, synced lyrics, collections, album notes, custom covers, band members and skins; your data stays on your PC. Built with Claude Code and released in ten days, then shaped by its first users' feedback. Tauri, Rust and TypeScript. [Download](https://github.com/shannonbay/crate/releases/latest)
- **[Rereader](https://shannonbay.github.io/rereader/)**: an Android app for reading and memorising the Bible by active recall: you pick the first letter of each word as you read. In testing on Google Play. Kotlin.

## Tools for AI coding agents

- **[Quarterdeck](https://github.com/shannonbay/Quarterdeck)** (formerly Conductor): a personal assistant that lives in Claude Code. You give it standing goals, like keeping an inbox under control or a GitHub profile current. Each goal runs on its own schedule in the background with its own memory, proposes what it wants to do, and waits for your approval in a Goals pane beside the chat or on your phone. Installs as a Claude Code plugin.
- **[create-skills](https://github.com/shannonbay/create-skills)**: an Agent Skill that writes new Agent Skills.
- **[setup-structure-index](https://github.com/shannonbay/setup-structure-index)**: a skill that keeps a lightweight map of a codebase up to date for the agent.
