# Hi, I'm Shannon

Senior software engineer in Wellington, New Zealand. Fifteen years of integration and platform work: real-time telecoms at Metaswitch, emergency-call routing at Spark, and border systems at New Zealand Customs. These days I also build and ship apps with AI coding agents.

## Apps I've shipped

- **[Crate](https://shannonbay.github.io/crate/)**: a music player for Windows built around albums and artists. Bulk tag editing, album notes, custom covers, band members and skins; your data stays on your PC. Built with Claude Code and released in ten days, then shaped by its first users' feedback. Tauri, Rust and TypeScript. [Download](https://github.com/shannonbay/crate/releases/latest)
- **[Rereader](https://shannonbay.github.io/rereader/)**: an Android app for reading and memorising the Bible by active recall: you pick the first letter of each word as you read. In testing on Google Play. Kotlin.

## Tools for AI coding agents

- **[Conductor](https://github.com/shannonbay/Conductor)**: an MCP server that gives an agent a persistent task tree outside its context window, so long-running work survives context compaction.
- **[create-skills](https://github.com/shannonbay/create-skills)**: an Agent Skill that writes new Agent Skills.
- **[setup-structure-index](https://github.com/shannonbay/setup-structure-index)**: a skill that keeps a lightweight map of a codebase up to date for the agent.
